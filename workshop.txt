description=This mod is currently in beta. It is being tested on a small dedicated server. Updates will continue for as long as I am playing the game.
description=
description=[b]Important:[/b] This mod is not a miracle fix. Project Zomboid has engine-level sync issues (corrupted combat packets, buffer errors, AI state locks) that no Lua mod can fully solve. JaysSync supplements the engine's native sync — it makes things better, not perfect. At worst, if the mod encounters an error, it silently falls back to vanilla sync behavior. It will never make things worse than they already are.
description=
description=Built for dedicated servers. Player, zombie, and vehicle position sync with dead reckoning for Build 42 multiplayer.
description=
description=Fixes crouch desync, frozen players, position drift, ghost zombies, and vehicle rubber-banding.
description=
description=This mod requires a dedicated server setup. Both the server and all clients need the mod installed. No effect in singleplayer.
description=
description=[h1]How It Works[/h1]
description=- Server reads authoritative positions and broadcasts to all clients
description=- Clients predict movement between updates using dead reckoning (velocity-based extrapolation)
description=- Position corrections are blended smoothly instead of teleporting
description=- Zombies near players are synced at higher priority to reduce combat desync
description=- Client stops overriding nearby zombies during combat to avoid fighting PZ's own combat system
description=- Vehicle states (engine, lights, siren) are also synced
description=- Every operation is error-protected — the mod cannot crash your server or client
description=
